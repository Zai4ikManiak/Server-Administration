
In order to optimize the backup process, ask yourself a couple of questions:

1. How frequently are the data in files changed?
    - **<ins>Daily</ins>**: The data is changed frequently and should be backuped each day.
    - **<ins>Weekly</ins>**: The data is changed rarely, however it can be changed a couple of times per month.
    - **<ins>Rarely</ins>**: The data is almost never changed.
